# VideoMate Legal & Support

Public static legal and support pages for VideoMate (`xyz.goirong.videomate`), operated by SGA VN.

This repository intentionally contains only public legal/support website files. It contains no application source code, credentials, keys, private configuration, analytics, cookies, or trackers.

Pages:

- `/` — Legal & Support
- `/privacy/` — Privacy Policy / Chính sách quyền riêng tư
- `/delete-account/` — Delete Account / Xóa tài khoản
- `/support/` — Support / Hỗ trợ

For privacy or support questions, use the repository’s public GitHub Issues mechanism. Do not submit passwords, payment information, identity documents, or other sensitive personal data in an issue.
