VideoMate Support
Hỗ trợ VideoMate

VideoMate uses this repository’s public GitHub Issues page for inquiries. Create a Privacy / Support inquiry.

Privacy inquiries / Câu hỏi quyền riêng tư

Ask about this policy, the categories of data described here, permissions, sharing, retention, or your available choices. Please do not place passwords, payment information, identity documents, chat content, or other sensitive personal data in a public issue.

Safety and reporting / An toàn và báo cáo

Use the in-app report and block tools whenever available to report content or another account. For a public safety or reporting-process inquiry, use the issue link above and avoid publishing sensitive details.

Account deletion / Xóa tài khoản

Account deletion is performed through the app: Profile → Pháp lý & an toàn (Legal & Safety) → Xóa tài khoản (Delete Account). Review the Delete Account information before proceeding.
